## darkroom

- 玩法：选照片或示例底片 → 显影（晃手机或手指划药盘）→ 定影（按住 4 秒）→ 开灯出片 → 存相册 / 发笔记。冲洗的好坏决定成片效果和冲洗报告。
- 文件分工：`bridge.js` 封装容器能力（陀螺仪、震动、存储、存相册、发笔记），`film.js` 是图像处理，`app.js` 是流程和交互，`index.html` / `style.css` 是界面。
- 1.0.0 只在本地打过包（`releases/darkroom-1.0.0.zip`，2026-11-19 10:48），对应基线提交 `9ca3f48`。
- 1.1.0、1.2.0 的改动见 `CHANGELOG.md`。1.2.0 新增镭射小卡：材质由冲洗结果决定（规则 `tasks/T-03-小卡/映射规则.md`，Kaisa 认为应改为随机，见 TODO T-13）、统一卡背翻开揭晓、2×3 暗房卡册、存晒卡图、陀螺仪倾斜。已验证：浏览器多视口完整流程，模拟宿主下的存档读写失败、陀螺仪多使用者、存卡时序（Codex 五轮审查），本地模拟器（Kaisa 验收）。**未实测**：切后台、真机陀螺仪和震动、存相册、发笔记、多指真机手感、Chrome 61 真机兼容。
