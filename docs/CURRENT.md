## darkroom

- 玩法：选照片或示例底片 → 显影（晃手机或手指划药盘）→ 定影（按住 4 秒）→ 开灯出片（可轻点相纸全屏看）→ 存相册 / 发笔记 → 拆一张镭射小卡、收进暗房卡册、存晒卡图。冲洗过程决定成片效果。小卡材质独立随机抽取，概率见 `tasks/T-03-小卡/映射规则.md`。
- 文件分工：`bridge.js` 封装容器能力（陀螺仪、震动、存储、存相册、发笔记），`film.js` 是图像处理，`app.js` 是流程和交互，`index.html` / `style.css` 是界面。
- 1.3.0 两批改动的内容见 `CHANGELOG.md`；第二批 Kaisa 2026-11-23 在本地测试页看过，说「可以先这样」，这一轮不再交 Codex 审。
- **创服本地模拟器（`redapp dev` 0.2.0）已实测**：iPhone 全屏模式用鼠标划药盘、长按定影、开灯、全屏预览和退出、揭晓及收集小卡。观察到「刚好」暖光和按钮呼吸、卡背浮动。开启系统减少动态效果的浏览器模拟后，药液位移、按钮呼吸和卡背浮动停止，暖光保留，小卡直接揭晓。存相册触发模拟器 JPG 下载，发笔记入口打开模拟编辑页。iPhone 半屏模式已查看首屏。
- **未实测**：Android / iOS 真机、Chrome 61、切后台、陀螺仪和震动、真机存相册和笔记编辑、多指手感。候选包 `releases/darkroom-1.3.0-rc-c9215d2.zip` 保留当前插画示例，目录和 ZIP 审计通过。
