## darkroom（暗房冲印店）

### 1.1.0 — 未发布

本地模拟器验收通过（Kaisa，2026-11-19）；真机未验证。

界面（Gemini 4 Neon 两轮实现）：
- 整体改成「物理暗房 × 胶片冲印工坊」风格：顶部悬挂安全灯，药盘上方标出 DEV / FIX，LED 样式的显影计时器
- 定影：按住时显示剩余秒数和进度；完成后「开灯」变成暖光主按钮，「定影已完成」退为弱化状态（修正原版按钮主次颠倒的问题）
- 开灯：加入短暂的闪光过渡
- 出片页：冲洗报告改成标签，存相册和发笔记两个按钮并排，去掉重复的标题，内容在不同屏高下垂直居中
- 划药盘时出现水波纹

交互修复（Claude，Codex 审查发现）：
- 多根手指划药盘不再能刷高「药水流动」读数，只认第一根手指
- 定影按钮只认开始按的那根手指；手指滑出按钮即松开；支持空格和回车按住定影
- 定影中切到后台会结束按压，后台时间不计入定影（未实测）
- 按住定影时直接开灯，定影不再在后台继续计时
- 陀螺仪每轮使用独立回调，上一轮迟到的启动结果不会影响当前这轮（模拟宿主下验证，真机未实测）
- 中途松手后「开灯」按钮出现时重新计算药盘尺寸，矮屏不再裁掉相纸底部
- 第二次出片时页面滚回顶部
