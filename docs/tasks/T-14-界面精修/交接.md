## 和 Gemini 协作（这一轮摸索出来的做法）

- 对话：https://gemini.google.com/app/e78e85701c608fb9 （模型 Gemini Neon）。Claude 用的是 Claude Desktop 内置浏览器里登录的账号；换浏览器要 Kaisa 自己登录。
- **给代码**：输入框左边「+」→「更多上传选项」→「导入代码」，填 `https://github.com/lcjayccc/xhs-mini-tools`。Gemini 会在沙箱里解压仓库，只能读到**已推送**的提交。子菜单点不开时，先聚焦「更多上传选项」再按方向键右。
- **本地没推送的改动**：告诉它「基线 = 某提交 + 哪些补丁」，并附三个文件的 sha256（按 LF 换行算），让它在沙箱里重建后核对。不要贴 diff：输入框会吃掉行首空格，diff 的上下文行会坏。
- **发消息**：长文本直接填进输入框；系统剪贴板粘贴在 Claude 的内置浏览器里不生效。
- **取回复**：回复正文的代码块可以用页面脚本按 `code-block` 元素抽出来；它在沙箱里跑的 Python 补丁脚本也在页面里，带精确的新旧片段，比正文更好核对。
- **落盘要人工核对**：Gemini 标的 CSS 行号会偏几行，按行号整段替换会误删别的规则，要按选择器或函数逐段替换。大改动它只给片段，不给整文件（一轮的工具调用次数有上限）。
