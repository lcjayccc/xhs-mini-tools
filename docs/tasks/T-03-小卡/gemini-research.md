## 已知的问题（来自视觉验收）

- 棱镜、彩虹、银镜、珠光的效果整层盖在照片上，照片几乎看不清，彩虹条纹尤其严重。小卡的主角是照片。
- 材质像是「一层渐变滤镜」，缺少真实镭射卡的物理感：卡纸的边、厚度、印刷细节、光只在某些区域亮起。
- 闪粉和蚀刻相对较好。

## 请调研这些方向（每个方向都要搜索，并给出来源链接）

1. **实体镭射卡**：K-pop 小卡（photocard）的常见工艺和版式；宝可梦等集换式卡牌的闪卡种类（如普通闪、反闪、宇宙闪、彩虹稀有、秘密稀有、全图闪）；国内谷圈的镭射卡、镭射票根、珠光纸、碎冰镭射等。重点：每种工艺在真实光线下**哪里亮、哪里不亮**，照片和镭射层是怎么共存的。
2. **网页上的镭射卡实现**：例如 simeydotme 的 pokemon-cards-css（poke-holo）、其他知名的 CSS / Canvas 全息卡实现、各种设计站上的 holographic card 案例。重点：用了哪些图层（光泽、眩光、遮罩、纹理），**怎样用遮罩只让局部区域反光，保住照片**。
3. **卡片本身的质感**：卡纸白边、圆角、厚度、边缘高光、印刷信息（编号、品牌标、小字）的排版，怎样让它像一张「真的卡」而不是一个发光的矩形。
4. **低端安卓 WebView 上的性能**：多层 `mix-blend-mode` 和 `filter` 在 3D 变换下的代价，业界怎么降级。
