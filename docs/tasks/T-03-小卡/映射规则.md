# 小卡材质抽取规则

状态：已定（Kaisa 2026-11-23）。依据：D-04。

## 抽取与稀有度

每轮开灯时独立抽取一次材质。同一轮的卡面、卡册和晒卡图共用这次结果。

| 材质 | 稀有度 | 每轮概率 |
|---|---|---:|
| 彩虹（Rainbow） | 普通 | 40% |
| 闪粉（Sparkle） | 特别款 | 12.5% |
| 珠光（Pearl） | 特别款 | 12.5% |
| 蚀刻（Etched） | 特别款 | 12.5% |
| 银镜（Chrome） | 特别款 | 12.5% |
| 棱镜（Prism） | 最稀有 | 10% |

显影时间、晃动、定影和瑕疵只影响本轮照片。卡册未收集项用材质的视觉特征作为线索。

## 收集

- 卡册经 `bridge.js` 的 `getList` / `setList` 读取和写入容器存储。继续使用 `darkroom.cards` 和原有材质标识，旧收集记录直接读取。
- 存储读取失败或不在小红书里时，收集进度只在本次打开期间有效。
