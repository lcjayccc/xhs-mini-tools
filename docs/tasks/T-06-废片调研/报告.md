# T-06 用户与「拯救废片」调研

汇总：Claude，2026-11-20（北京时间）。来源：Gemini Deep Research（引用 162 个来源，原文 `.review/t06-research/gemini-deep.txt`）、Gemini 普通模式回答（`gemini-quick.txt`）、Claude 联网搜索。来源等级同 T-05 报告。

## 结论

1. **女生最常见、也最值得救的废片，正好能在我们的限制下救。** 频次最高的是光线问题（逆光黑脸、阴天发灰、局部过曝）和色彩问题（肤色发黄发灰、原图寡淡）。这两类靠调色、曲线、色彩映射表、颗粒、光晕就能救，**不需要 AI**（C/B：小红书教程和消费社区经验，Gemini 汇总；没有官方占比数据）。
2. **需要 AI 的能力明确不做**：消除路人、换天换背景、修复严重失焦、提高清晰度、改表情。硬做只会出现评论区最反感的「塑料感、假白、灰浆」。
3. **口碑的关键在于「不翻车」，而不是「滤镜多」。** 用户最在意的是肤色：不能假白、不能发黄发灰、磨皮不能把妆糊掉。另外，用户越来越反感烂大街的网红滤镜，「朋友一眼认出是哪个滤镜」本身就是社交尴尬（C，社区观察）。
4. **社区修图 Skill 最值得借鉴的是工作顺序，不是参数**：先量化诊断（直方图、白平衡）→ 校正曝光和白平衡 → 套风格 → 单独处理肤色 → 最后加颗粒和光晕，每一步都有安全上限。这个流程可以「编译」成我们本地的固定流水线（B/C，见下方 Skill 列表，未逐个打开核实）。

## 用户眼中的废片

| 类型 | 典型情况 | 热度（定性） | 我们能救吗 |
|---|---|---|---|
| 光线失衡 | 逆光黑脸、阴天发灰、隔玻璃发雾、顶光阴阳脸、天空死白 | 极高 | **能**。压高光、提阴影、去灰、高光柔和滚落；彻底过曝死白的地方救不回 |
| 色彩和肤色 | 肤色发黄发灰或假白、原图寡淡没情绪 | 极高 | **能**。白平衡、HSL、曲线、色彩映射表的主场 |
| 构图和背景乱 | 路人、杂物、地平线歪 | 高 | 部分：重新裁剪、加边框排版、暗角拉回视线；消除路人不行 |
| 糊和噪点 | 手抖、失焦、夜景噪点 | 中高 | 部分：轻微发软可以锐化；严重的转成 CCD 柔焦或胶片颗粒风，「把缺陷变成氛围」 |
| 表情和形象 | 闭眼、表情僵、油光 | 中 | 基本不行；只做轻度柔肤 |
| 天气场景 | 想换蓝天、加雪 | 中 | 不行（需要生成式 AI） |

一个产品上有用的观察：阴天没有硬阴影、逆光自带发丝轮廓光，这两类「废片」救好之后往往比晴天硬光更有杂志感。所以入口可以直接写「救阴天」「救逆光」，而不是「滤镜」。

## 热门风格（参数为社区经验，只作起点）

| 风格 | 视觉特征 | 要点 |
|---|---|---|
| 胶片风（柯达 Portra、富士、过期卷） | 低饱和、柔和对比、暖肤色或清冷暗部、颗粒 | 常青风格；过期卷颗粒更重、偏冷褪色 |
| CCD 复古数码 | 柔而不糊、冷白皮基底加暖高光、阴影偏青蓝高光偏暖、大颗粒、细白边和日期 | **两份 Gemini 回答对对比度和锐化的建议相反**，说明参数没有共识，要自己调 |
| 韩系奶油、日系清透 | 明亮、低对比、阴影抬起、微暖或微冷 | 翻车率高：暗片照抄低对比参数会变「灰浆」「芒果黄皮」，**套风格前要先自动校正曝光和白平衡** |
| 复古港风、氛围暗调 | 压高光、压暗背景偏青蓝、保住暖橘肤色和红唇、暗角、光晕 | 光晕在免费工具里少见，容易被追问「用的什么滤镜」 |
| 拍立得、撕拉片、半格排版 | 白边、黑框、纸纹、日期、大留白 | 纯 Canvas 2D 就能做，能把构图差的照片包装成「杂志感」 |
| 醒图「邪修」 | 黑色涂鸦柔光去雾、浅色画笔柔光打光 | 本质是图层混合数学，天然适合做成我们的一键或手指功能 |

## 在我们的限制下能做什么

| 能力 | 结论 | 做法 |
|---|---|---|
| 曲线、去灰、高光阴影 | 能，效果可对标专业 App | 一次着色器处理 |
| 风格色彩映射表、色调分离 | 能 | 2D 平铺纹理（WebGL 1 没有 3D 纹理）；33³ 的表 PNG 约 100 KB 以内 |
| 肤色保护、HSL、自然饱和度 | 能 | 按色相权重定向调橙黄 |
| 颗粒、光晕、柔焦、暗角 | 能 | 预烘焙颗粒纹理加亮度响应；1/4 分辨率模糊 |
| 自动白平衡和曝光 | 能，极端光下偶有偏差 | 缩略图直方图加灰世界算法，设安全上限，留开关 |
| 裁剪、边框、组图统一 | 能 | Canvas 2D |
| 局部补光（逆光救脸） | 近似可用 | 按暖肤色和暗部权重自动温和提亮；或手指涂抹柔光 |
| 柔肤 | 只做轻度 | 肤色区保边模糊，强度封顶并回补纹理 |
| 去模糊、超分、换背景、消除路人、改表情 | **不做** | 需要神经网络 |

## 适合优先做的功能（Gemini 建议，Claude 认可排序）

1. **一键去灰通透和逆光救脸**：所有风格的基础，第一秒就能看到「救活了」。
2. **独立的肤色保护**：防翻车的护城河，常驻开关。
3. **胶片馆**：柯达暖人像、富士清冷、电影纪实、过期卷，4～5 套精调色彩映射表加颗粒。
4. **CCD 柔焦闪光灯风**：传播力强，还能把轻微糊片变成氛围。
5. **防翻车的韩系奶油和日系清透**：先自动校正再套风格。
6. **港风和暗调，带红橙光晕**。
7. **拍立得、撕拉片、半格排版，加组图一键统一色调**。

## 和 T-05 的交叉点

T-05 的「出片质感包」（色彩映射表、颗粒、光晕、影调曲线）和这里的第 3、4、6 项**是同一套引擎**。不管暗房冲印店最后选哪个方向，这套「成片引擎」都要做，而且做一次两边都能用。
